
# Правила для нейросети (rules.md)

**Назначение:** единый свод правил генерации кода на C для базы знаний по курсу.
**Диалект:** строго C (C99/C11).
**Приоритет источников:** docx-примеры (уровень 1) → лекции (уровень 2) → стандарт C (уровень 3).

---

## 1. Приоритет источников

| Уровень | Источник | Как использовать |
|---------|----------|------------------|
| **1 (высший)** | docx-примеры (принятые работы) | Копировать **дословно** (с заменой C++ → C). Имена переменных, отступы, `return;` — сохранять |
| **2** | Лекции (с исправленными опечатками) | Брать код, исправлять опечатки с пометкой `// БЫЛО: ... → СТАЛО: ...` |
| **3** | Стандарт C | Только если нет в первых двух. Помечать `// [ИЗ СТАНДАРТА C]` |

---

## 2. Запрет на импровизацию

- Брать код **только** из `templates/`
- Если шаблона нет — **остановиться и спросить пользователя**, не писать с нуля
- Не добавлять «улучшения» (оптимизацию, другие имена, другой стиль)

---

## 3. Обязательное уточнение

Перед генерацией кода спросить:
> «Есть ли в базе шаблон для [задача]? Использовать его дословно или адаптировать под новые данные?»

---

## 4. Запрет на оптимизацию

- Не менять логику алгоритма без явного разрешения
- Даже если решение неэффективно (два прохода вместо одного) — оставить как в шаблоне
- Формулы — **дословно** (например, `x[i]/(y[j]+x[i]*x[i])` — не упрощать)

---

## 5. Диалект — строго C (C99/C11)

### 5.1. Игнорировать C++

| C++ | C-эквивалент | Пометка |
|-----|--------------|---------|
| `#include <iostream>` | удалить | — |
| `new T[n]` | `(T*)malloc(n * sizeof(T))` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `new T*[n]` | `(T**)malloc(n * sizeof(T*))` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `delete[] ptr` | `free(ptr)` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `float *&x` (параметр) | `float **x` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `int& imax` (параметр) | `int *imax` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `x[i]` (если `x` — `float**`) | `(*x)[i]` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `bool` / `true` / `false` | `<stdbool.h>` + `bool` / `true` / `false` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` (C99) |
| `class` / `public` / `private` | `struct` + функции | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `std::string` | `char[]` / `char*` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `cin` / `cout` | `scanf` / `printf` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |

### 5.2. Обязательные `#include` (по темам)

| Тема | Заголовки |
|------|-----------|
| Ввод-вывод | `<stdio.h>` |
| Динамическая память | `<stdlib.h>` (или `<malloc.h>` — по стилю docx) |
| Математика (`pow`, `sqrt`) | `<math.h>` |
| Строки | `<string.h>` |
| Логический тип (C99) | `<stdbool.h>` |

## 6. Опечатки

- Исправлять синтаксические ошибки (пропущенные `;`, неверные спецификаторы `printf`)
- Помечать: `// БЫЛО: [оригинал] → СТАЛО: [исправление]`

### 6.1. Сводка опечаток преподавателя

| Опечатка | Исправление | Где |
|----------|-------------|-----|
| `s\n` | `s / n` | Лекция 6, слайд 10 |
| `1.0\n` | `1.0 / n` | Лекция 6, слайд 10 |
| `s\k` | `s / k` | Лекция 6, слайд 12 |
| `1.0\k` | `1.0 / k` | Лекция 6, слайд 12 |
| `index=I` | `index=i` | Лекция 6, слайд 14 |
| `True` / `False` | `true` / `false` (или `1`/`0`) | Лекция 6, слайды 16, 18 |
| `and` | `&&` | Лекция 6, слайды 16, 18 |
| `if A[i]>0:` | `if (A[i] > 0) {` | Лекция 6, слайд 12 |
| `k=0` (в счётчике) | `k++` | Лекция 6, слайд 12 |
| `'строка'` | `"строка"` | Лекция 6, слайд 12 |
| `printf("\n")` без `;` | `printf("\n");` | Лекция 7, слайд 2 |
| `printf("\n")` вне внешнего цикла | внутри внешнего, после внутреннего | Лекция 7, слайд 2 |
| `const char '...'` | `const char *"..."` | Лекция 12, слайд 4 |
| `malloc(r * sizeof(int))` | `malloc((r - l + 1) * sizeof(int))` | Лекция 12, слайд 15 |
| Нет `free` после `malloc` | Добавить `free` | Лекция 12, слайды 11–18 |
| Нет проверки `NULL` | Добавить `if (ptr == NULL)` | Лекция 12, слайды 11–18 |
| Нет `#include <stdlib.h>` | Добавить | Лекция 12, слайды 11–18 |
| `date bd;` (в структуре) | `struct date bd;` | Лекция 14, слайд 9 |
| `types value;` | `union types value;` | Лекция 14, слайд 16 |
| `ИмяСтруктуры ИмяМассива` | `struct ИмяСтруктуры ИмяМассива` | Лекция 14, слайд 18 |
| `book library[3];` | `struct book library[3];` | Лекция 14, слайд 19 |
| `union ... { ... }` без `;` | `union ... { ... };` | Лекция 14, слайд 14 |
| `%x` для `unsigned char` | `(unsigned int)value.b[i]` | Лекция 14, слайд 16 |

## 7. Стиль преподавателя (приоритет — docx)

### 7.1. Имена переменных (дословно из docx)

`A`, `n`, `i`, `j`, `x`, `y`, `nx`, `C`, `P`, `s`, `t`, `fl`, `z`, `imax`, `jmax`, `Max`, `ch`, `fp`

> Копировать **дословно** из docx-примеров. Сохранять «дурацкие» флаги и промежуточные переменные.

### 7.2. Имена функций (CamelCase)

`VvodVect`, `VivodVect`, `Sum`, `Check`, `FormMatrix`, `VivodMatrix`, `FindMax`, `FreeMemoryMatrix`, `FreeMemoryVector`

> Глаголы: `Vvod`, `Vivod`, `Form`, `Find`, `Free`. Первая буква — заглавная.

### 7.3. Форматирование

- Отступ — **4 пробела** (не табы)
- Фигурные скобки — на **новой строке**
- `for` / `while` / `if` — без пробела между ключевым словом и `(`: `for(...)`, `if(...)`, `while(...)`
- Внутри `for` — пробелы вокруг `;`: `for (int i=0; i<n; i++)`
- `scanf` / `printf` — без пробела после запятой: `scanf("%i",&n)`, `printf("%i ",A[i])`
- **`return;` в конце каждой `void`-функции** (стиль преподавателя!)
- **Пустая строка** между функциями
- `printf ("...")` — пробел между `printf` и `(` (если в docx так)

### 7.4. Спецификаторы `printf` / `scanf`

| Тип | Спецификатор |
|-----|--------------|
| `int` | `%i` (не `%d`!) |
| `float` | `%f` |
| `double` | `%lf` (для `scanf`) / `%f` (для `printf`) |
| `char` | `%c` |
| `char*` (строка) | `%s` |

> **Важно:** преподаватель использует **`%i`** для `int` (а не `%d`). Сохранить!

### 7.5. Работа с памятью

- **C++ (оригинал):** `new` / `delete[]`
- **C (наш диалект):** `malloc` / `free`
- **Проверка `NULL`:** в docx **отсутствует** → добавить с пометкой `// добавлено по правилам базы`
- **Освобождение памяти:** в docx **есть** (`FreeMemoryMatrix`, `FreeMemoryVector`) → сохранить

### 7.6. Обработка ошибок

- В docx **нет проверок** `if (ptr == NULL)` после `new`
- В docx **нет** `if (fp == NULL)` после `fopen`
- **Правило базы:** добавить проверки с пометкой

---

## 8. Полнота извлечения

- Не пропускать «очевидные» вещи (проверки `if (x == NULL)` после `malloc`)
- Выписывать **все** `#include`, даже стандартные
- Повторяющиеся темы объединять с пометкой `[ПОВТОР: лекции X, Y]`

---

## 9. Добавлять всегда (даже если в docx нет)

- `if (ptr == NULL) return;` после `malloc`
- `if (fp == NULL) return 1;` после `fopen`
- `free(ptr)` после работы с `malloc`
- `fclose(fp)` после работы с файлом
- `return 0;` в конце `main`

```

## 11. Чек-лист перед генерацией кода

- [ ] Шаблон найден в `templates/`?
- [ ] Если нет — остановился и спросил пользователя?
- [ ] Все `#include` выписаны?
- [ ] `%i` для `int` (не `%d`)?
- [ ] `return;` в конце каждой `void`-функции?
- [ ] `malloc` + проверка `NULL` + `free`?
- [ ] `fopen` + проверка `NULL` + `fclose`?
- [ ] `return 0;` в конце `main`?
- [ ] Имена переменных — дословно из docx?
- [ ] Имена функций — CamelCase?
- [ ] Формулы — дословно (не упрощены)?
- [ ] C++-конструкции заменены с пометкой `[ИСПРАВЛЕНО ДИАЛЕКТ]`?
- [ ] Опечатки исправлены с пометкой `// БЫЛО: ... → СТАЛО: ...`?
