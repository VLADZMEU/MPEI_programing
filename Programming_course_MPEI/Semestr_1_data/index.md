## 2. Стиль преподавателя (`style-guide.md`)

**Источник:** docx-примеры (уровень 1). Код копировать дословно (с заменой C++ → C).

### 2.1. Имена переменных (дословно)
`A`, `n`, `i`, `j`, `x`, `y`, `nx`, `C`, `P`, `s`, `t`, `fl`, `z`, `imax`, `jmax`, `Max`, `ch`, `fp`

### 2.2. Имена функций (CamelCase)
`VvodVect`, `VivodVect`, `Sum`, `Check`, `FormMatrix`, `VivodMatrix`, `FindMax`, `FreeMemoryMatrix`, `FreeMemoryVector`

### 2.3. Форматирование
- `%i` для `int` (не `%d`!)
- `%f` для `float`
- `return;` в конце каждой `void`-функции
- `printf ("...")` — пробел между `printf` и `(`
- `scanf("%i",&n)` — без пробела после запятой
- `for (int i=0; i<nx;i++)` — без пробела после `;` в третьей части
- Фигурные скобки на новой строке
- 4 пробела (не табы)

### 2.4. Чек-лист
- [ ] `#include <stdio.h>` — обязательно
- [ ] `#include <stdlib.h>` — для `malloc`/`free`
- [ ] `#include <stdbool.h>` — если есть `bool`
- [ ] `#include <math.h>` — если есть `pow`, `sqrt`
- [ ] `malloc` + проверка `NULL` + `free`
- [ ] `fopen` + проверка `NULL` + `fclose`
- [ ] `return 0;` в конце `main`
- [ ] Формулы — дословно (не упрощать!)

## 4. Правила (`rules.md`)

### 4.1. Приоритет источников
1. **Уровень 1:** docx-примеры — копировать дословно (с заменой C++ → C)
2. **Уровень 2:** лекции (с исправлением опечаток)
3. **Уровень 3:** стандарт C

### 4.2. Запрет на импровизацию
- Брать код **только** из `templates/`
- Если шаблона нет — **остановиться и спросить пользователя**, не писать с нуля

### 4.3. Запрет на оптимизацию
- Не менять логику алгоритма без явного разрешения
- Даже если решение неэффективно — оставить как в шаблоне

### 4.4. Диалект — строго C (C99/C11)
- Игнорировать C++: `new/delete`, `cin/cout`, `&`-ссылки, `class`, `std::string`
- Заменять на: `malloc/free`, `printf/scanf`, указатели, `struct`
- Помечать: `// БЫЛО: [X] → СТАЛО: [Y]`

### 4.5. Обязательные `#include` (по темам)

| Тема | Заголовки |
|------|-----------|
| Ввод-вывод | `<stdio.h>` |
| Динамическая память | `<stdlib.h>` (или `<malloc.h>` — по стилю docx) |
| Математика (`pow`, `sqrt`) | `<math.h>` |
| Строки | `<string.h>` |
| Логический тип (C99) | `<stdbool.h>` |

## 5. Сводка C++ → C замен

| C++ | C | Пометка |
|-----|---|---------|
| `#include <iostream>` | удалить | — |
| `new T[n]` | `(T*)malloc(n * sizeof(T))` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `new T*[n]` | `(T**)malloc(n * sizeof(T*))` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `delete[] ptr` | `free(ptr)` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `float *&x` (параметр) | `float **x` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `int& imax` (параметр) | `int *imax` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `x[i]` (если `x` — `float**`) | `(*x)[i]` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `bool` / `true` / `false` | `<stdbool.h>` + `bool` / `true` / `false` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` (C99) |
| `class` / `public` / `private` | `struct` + функции | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |
| `std::string` | `char[]` / `char*` | `[ИСПРАВЛЕНО ДИАЛЕКТ]` |

## 6. Сводка опечаток преподавателя (исправлять с пометкой)

| Опечатка | Исправление | Где |
|----------|-------------|-----|
| `s\n` | `s / n` | Лекция 6, слайд 10 |
| `1.0\n` | `1.0 / n` | Лекция 6, слайд 10 |
| `s\k` | `s / k` | Лекция 6, слайд 12 |
| `1.0\k` | `1.0 / k` | Лекция 6, слайд 12 |
| `index=I` | `index=i` | Лекция 6, слайд 14 |
| `True` / `False` | `true` / `false` (или `1`/`0`) | Лекция 6, слайды 16, 18 |
| `and` | `&&` | Лекция 6, слайды 16, 18 |
| `if A[i]>0:` | `if (A[i] > 0) {` | Лекция 6, слайд 12 |
| `k=0` (в счётчике) | `k++` | Лекция 6, слайд 12 |
| `'строка'` | `"строка"` | Лекция 6, слайд 12 |
| `printf("\n")` без `;` | `printf("\n");` | Лекция 7, слайд 2 |
| `printf("\n")` вне внешнего цикла | внутри внешнего, после внутреннего | Лекция 7, слайд 2 |
| `const char '...'` | `const char *"..."` | Лекция 12, слайд 4 |
| `malloc(r * sizeof(int))` | `malloc((r - l + 1) * sizeof(int))` | Лекция 12, слайд 15 |
| Нет `free` после `malloc` | Добавить `free` | Лекция 12, слайды 11–18 |
| Нет проверки `NULL` | Добавить `if (ptr == NULL)` | Лекция 12, слайды 11–18 |
| Нет `#include <stdlib.h>` | Добавить | Лекция 12, слайды 11–18 |
| `date bd;` (в структуре) | `struct date bd;` | Лекция 14, слайд 9 |
| `types value;` | `union types value;` | Лекция 14, слайд 16 |
| `ИмяСтруктуры ИмяМассива` | `struct ИмяСтруктуры ИмяМассива` | Лекция 14, слайд 18 |
| `book library[3];` | `struct book library[3];` | Лекция 14, слайд 19 |
| `union ... { ... }` без `;` | `union ... { ... };` | Лекция 14, слайд 14 |
| `%x` для `unsigned char` | `(unsigned int)value.b[i]` | Лекция 14, слайд 16 |
