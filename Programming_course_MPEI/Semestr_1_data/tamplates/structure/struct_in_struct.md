
### Структура в структуре
**Источник:** Лекция 14 (слайд 9), `style-guide.md`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
#include <stdio.h>
#include <string.h>                     // для strcpy

// Вложенная структура (слайд 9)
struct date
{
    int day;
    char month[20];
    int year;
};

// Внешняя структура (слайд 9)
struct persone
{
    char firstname[20];
    char lastname[20];
    // БЫЛО: date bd; (без struct — C++)
    // СТАЛО: struct date bd; (в C обязателен struct)
    struct date bd;
};

int main()
{
    struct persone p;

    // Заполнение полей (стиль преподавателя: strcpy для строк)
    strcpy(p.firstname, "Ivan");        // добавлено по правилам базы
    strcpy(p.lastname, "Ivanov");       // добавлено по правилам базы

    // Обращение к полям вложенной структуры — через две точки
    p.bd.day = 8;
    strcpy(p.bd.month, "июня");         // добавлено по правилам базы
    p.bd.year = 1978;

    // Вывод: %i для int (стиль преподавателя), %s для строк
    printf("%s %s, %i %s %i\n",
           p.firstname, p.lastname,
           p.bd.day, p.bd.month, p.bd.year);

    return 0; // добавлено по правилам базы
}
```

**Ключевые особенности стиля:**
- `struct date bd;` — **в C обязателен `struct`** внутри другой структуры (в C++ можно без).
- Обращение к полям: `p.bd.day` (двойная точка для вложенной структуры).
- `strcpy` для строковых полей (массивы не присваиваются).
- `%i` для `int` (стиль преподавателя, `style-guide.md` п. 1.4).
- `%s` для строк.

**Частые ошибки преподавателя (опечатки):**
- В оригинале (слайд 9): `date bd;` — **без `struct`** (C++). Исправлено на `struct date bd;`.
- `persone` (с `e` на конце) — **опечатка** (вероятно, `person`). Сохранено как в оригинале (стиль преподавателя).
