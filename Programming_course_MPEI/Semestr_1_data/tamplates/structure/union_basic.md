### Объединения (union): описание и использование
**Источник:** Лекция 14 (слайды 13–16), `style-guide.md`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
#include <stdio.h>

// Объявление объединения (слайд 14)
// БЫЛО: union ИмяОбъединения { ... } (без ; в конце — ошибка)
// СТАЛО: union ... { ... }; (с ;)
union types
{
    float f;
    unsigned char b[4];
};

int main()
{
    // БЫЛО: types value; (без union — C++)
    // СТАЛО: union types value; (в C обязателен union)
    union types value;

    // Инициализация (слайд 16)
    // В объединении в каждый момент времени активно только одно поле
    value.f = 3.14f;

    // Вывод (слайд 16): интерпретация байтов float как unsigned char
    // %x для unsigned char — приводим к unsigned int (иначе UB)
    printf("N = %f = %x %x %x %x\n",
           value.f,
           (unsigned int)value.b[0],
           (unsigned int)value.b[1],
           (unsigned int)value.b[2],
           (unsigned int)value.b[3]);

    return 0; // добавлено по правилам базы
}
```

**Ключевые особенности стиля:**
- `union ИмяОбъединения { ... };` — **обязательна `;` после `}`** (слайд 14).
- `union types value;` — **с `union`** (в C обязательно, если нет `typedef`).
- Все поля разделяют **одну область памяти** (слайд 13).
- Для вывода `unsigned char` через `%x` — приведение к `(unsigned int)` (иначе UB).

**Частые ошибки преподавателя (опечатки):**
- В оригинале (слайд 14): `union ... { ... }` — **без `;`**. Исправлено.
- В оригинале (слайд 16): `types value;` — **без `union`** (C++). Исправлено на `union types value;`.
- В оригинале (слайд 16): `printf("%f = %x ...", value.b[0], ...)` — `%x` для `unsigned char`. `%x` ожидает `unsigned int`, поэтому добавлено приведение `(unsigned int)`.
