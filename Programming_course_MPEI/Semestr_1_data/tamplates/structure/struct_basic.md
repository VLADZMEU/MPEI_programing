
### Базовое описание структуры и обращение к полям
**Источник:** Лекция 14 (слайды 4–6), `style-guide.md`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
#include <stdio.h>
#include <string.h>                     // для strcpy (если нужно копировать строку)

// Описание структуры (слайд 4)
struct date
{
    int day;
    char month[20];
    int year;
};

int main()
{
    // Объявление переменной типа struct date
    // БЫЛО: date bd; (C++) → СТАЛО: struct date bd; (C)
    struct date bd;

    // Обращение к полям (слайд 6)
    bd.day = 8;
    
    // В C строке нельзя просто присвоить литерал:
    // БЫЛО: bd.month = "июня"; (ОШИБКА в C, работает только в C++)
    // СТАЛО: strcpy(bd.month, "июня");
    strcpy(bd.month, "июня");           // добавлено по правилам базы (в лекции нет)
    
    bd.year = 1978;

    // Вывод полей (слайд 6)
    // БЫЛО: printf("%d %s %d", bd.day, bd.month, bd.year);
    // СТАЛО: %i для int (стиль преподавателя)
    printf("%i %s %i\n", bd.day, bd.month, bd.year);

    return 0; // добавлено по правилам базы
}
```

**Ключевые особенности стиля:**
- `struct ИмяСтруктуры { ... };` — **обязательна `;` после `}`** (слайд 4).
- Перед именем структуры **нужен `struct`**: `struct date bd;` (в C, а не C++).
- Обращение к полям через точку: `bd.day` (слайд 6).
- `%i` для `int` (стиль преподавателя, `style-guide.md` п. 1.4).
- `%s` для строк (массивов `char`).
- **Для присваивания строки** — `strcpy` (в C массивы не присваиваются).

**Частые ошибки преподавателя (опечатки):**
- `date bd;` (без `struct`) — **C++**, в C нужно `struct date bd;`.
- `bd.month = "июня";` — **ошибка в C** (массивы не присваиваются). Нужно `strcpy(bd.month, "июня");` или инициализация при объявлении (см. `struct_init.md`).
- В лекции (слайд 6): `printf("%d %s %d", ...)` — `%d` для `int`. Заменено на `%i` (стиль преподавателя).
