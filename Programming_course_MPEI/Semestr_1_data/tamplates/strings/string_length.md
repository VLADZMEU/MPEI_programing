
### Длина строки
**Источник:** Лекция 13 (слайд 10), `style-guide.md`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
#include <stdio.h>
#include <string.h>                     // для strlen

int main()
{
    char str[100] = "Hello, World!";
    size_t len;

    // Вычисление длины строки (слайд 10)
    len = strlen(str);

    // strlen возвращает size_t; приводим к int для %i (стиль преподавателя)
    printf("Длина строки: %i\n", (int)len);

    return 0;                           // добавлено по правилам базы
}
```

**Ключевые особенности стиля:**
- `#include <string.h>` для `strlen`.
- `strlen` возвращает `size_t` (беззнаковый тип).
- Приведение к `int` для вывода через `%i` (стиль преподавателя, `style-guide.md` п. 1.4).
- Альтернатива: `printf("%zu\n", len);` (C99, но `%zu` — не стиль преподавателя).

**Частые ошибки преподавателя (опечатки):**
- Нет (код корректен).
- **Не путать:** `sizeof(str)` — размер массива (100), `strlen(str)` — фактическая длина строки (до `'\0'`).
```

[ТРЕБУЕТ ПРОВЕРКИ: в лекции 13 (слайд 10) дан только прототип `size_t strlen(const char *string);` без примера использования. Шаблон составлен на основе правил `style-guide.md` (имена `str`, `len`, `%i`). Если в docx-примерах есть готовый код для `strlen` — заменить на дословный с пометкой `// [ИЗ DOCX]`.]
[ТРЕБУЕТ ПРОВЕРКИ: `char str[100]` — размер выбран произвольно (100). Если в docx-примерах другой размер — заменить с пометкой `// БЫЛО: 100 → СТАЛО: [размер из docx]`.]
[ТРЕБУЕТ ПРОВЕРКИ: `(int)len` — приведение `size_t` к `int` для `%i`. Если `len > INT_MAX` (теоретически) — UB. Если по правилам базы нужно `%zu` — заменить с пометкой `// БЫЛО: %i → СТАЛО: %zu (C99)`.]
[ТРЕБУЕТ ПРОВЕРКИ: `printf("Длина строки: %i\n", (int)len);` — `%i` для `int` (стиль преподавателя). Если в docx `%d` — заменить с пометкой `// БЫЛО: %i → СТАЛО: %d (по стилю docx)`.]
```
