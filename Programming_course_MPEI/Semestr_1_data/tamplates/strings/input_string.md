### 1. `templates/strings/input_string.md`

```markdown
### Ввод строки с клавиатуры
**Источник:** Лекция 13 (`<string.h>`), `style-guide.md`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
#include <stdio.h>
#include <string.h>                     // для strlen

int main()
{
    char str[100];                      // статический массив символов (слайд 2, 4)

    printf("Введите строку: ");

    // fgets — безопасная функция ввода (слайд 5)
    // Читает не более size-1 символов + '\0'
    if (fgets(str, sizeof(str), stdin) == NULL) {
        return 1;                       // добавлено по правилам базы
    }

    // Удаление символа новой строки '\n', который добавляет fgets
    size_t len = strlen(str);
    if (len > 0 && str[len-1] == '\n') {
        str[len-1] = '\0';
    }

    printf("Вы ввели: %s\n", str);
    return 0;                           // добавлено по правилам базы
}
```

**Ключевые особенности стиля:**
- `fgets` вместо `gets` (лекция 13, слайд 5: `gets` удалена в C11 из-за переполнения буфера).
- Статический массив `char str[100];` (константа — безопаснее, слайд 4).
- Формат `%s` для вывода строки.
- `return 0;` в конце `main`.

**Частые ошибки преподавателя (опечатки):**
- `gets()` — **не использовать** (удалена в C11).
- `char* s = (char*)malloc(...)` — динамическая строка (слайд 2), но требует `free(s)`.
```

### 2. `templates/strings/string_convert.md`

```markdown
### Преобразование строки в число
**Источник:** Лекция 13 (слайд 7), `style-guide.md`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
#include <stdio.h>
#include <stdlib.h>                     // для atoi/atof/strtol

int main()
{
    char str[20];
    int num;

    printf("Введите число: ");
    if (scanf("%19s", str) != 1) {      // добавлено по правилам базы
        return 1;
    }

    // Преобразование строки в int (слайд 7)
    num = atoi(str);

    // Альтернативы:
    // double d  = atof(str);           // строка → double
    // long l    = atol(str);           // строка → long
    // long long ll = atoll(str);       // строка → long long

    printf("Число: %i\n", num);         // %i для int (стиль преподавателя)
    return 0;                           // добавлено по правилам базы
}
```

**Ключевые особенности стиля:**
- `#include <stdlib.h>` для `atoi`/`atof`/`strtol` (слайд 7).
- `%i` для `int` (стиль преподавателя).
- Проверка результата `scanf`.

**Частые ошибки преподавателя (опечатки):**
- **Опечатка в лекции (слайд 7):** `long long int atoll(long long int char *string)` → правильно `long long int atoll(const char *string);` (исправлено).
- Для безопасного преобразования с проверкой ошибок — использовать `strtol`/`strtod` (слайды 8–9), а не `atoi`/`atof`.
```

### 3. `templates/strings/string_length.md`

```markdown
### Длина строки
**Источник:** Лекция 13 (слайд 10), `style-guide.md`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
#include <stdio.h>
#include <string.h>                     // для strlen

int main()
{
    char str[100] = "Hello, World!";
    size_t len;

    // Вычисление длины строки (слайд 10)
    len = strlen(str);

    // strlen возвращает size_t; приводим к int для %i (стиль преподавателя)
    printf("Длина строки: %i\n", (int)len);

    return 0;                           // добавлено по правилам базы
}
```

**Ключевые особенности стиля:**
- `#include <string.h>` для `strlen`.
- `strlen` возвращает `size_t` (беззнаковый тип).
- Приведение к `int` для вывода через `%i` (стиль преподавателя, `style-guide.md` п. 1.4).
- Альтернатива: `printf("%zu\n", len);` (C99, но `%zu` — не стиль преподавателя).

**Частые ошибки преподавателя (опечатки):**
- Нет (код корректен).
- **Не путать:** `sizeof(str)` — размер массива (100), `strlen(str)` — фактическая длина строки (до `'\0'`).
```
