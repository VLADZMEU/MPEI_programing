
### Чтение чисел из текстового файла
**Источник:** `пример чтения файла.docx`
**Диалект:** C (C99)

**Шаблон кода:**
```c
#include <stdio.h>
int main()
{
    int ch;
    FILE *fp = fopen("1.txt", "r");
    if (fp == NULL) return 1;           // добавлено по правилам базы
    for (int i=0; i<10; i++)
    {
        fscanf(fp,"%i ",&ch);
        printf("%i ",ch);
    }
    fclose(fp);                         // добавлено (в оригинале нет)
    return 0;                           // добавлено (слайд обрывается)
}
```

**Ключевые особенности стиля:**
- `fscanf(fp,"%i ",&ch)` — **без пробела** после запятой, **с пробелом** после `%i` в формате
- `printf("%i ",ch)` — **с пробелом** после `%i`
- `FILE *fp` — имя `fp`
- `int ch` — имя `ch`

**Частые ошибки преподавателя (опечатки):**
- Нет `fclose(fp)` — утечка, добавить
- Нет проверки `fp == NULL` — добавить
- Нет `return 0;` — добавить
```

[ТРЕБУЕТ ПРОВЕРКИ: шаблон в `all_data.md` взят из docx-примера (`пример чтения файла.docx`). В оригинале docx код был на C (без C++-вкраплений), но без `fclose`, проверки `NULL` и `return 0;`. Эти добавления помечены. Если в docx эти строки есть — убрать пометки «добавлено».]
[ТРЕБУЕТ ПРОВЕРКИ: `fscanf(fp,"%i ",&ch)` — пробел после `%i` в формате заставляет `fscanf` пропускать пробелы/переводы строк после числа. Это **стиль преподавателя** (сохранить). Если по правилам базы нужно убрать пробел — пометить `// БЫЛО: "%i " → СТАЛО: "%i"`.]
[ТРЕБУЕТ ПРОВЕРКИ: `for (int i=0; i<10; i++)` — жёстко заданное число 10 (из docx). Если нужно читать до конца файла — заменить на `while (fscanf(fp,"%i ",&ch) == 1)`. Но это **изменение логики** — запрещено без разрешения пользователя.]
[ТРЕБУЕТ ПРОВЕРКИ: `printf("%i ",ch)` — `%i` для `int` (стиль преподавателя). Если в docx `%d` — заменить с пометкой `// БЫЛО: %i → СТАЛО: %d (по стилю docx)`.]
[ТРЕБУЕТ ПРОВЕРКИ: шаблон не проверяет результат `fscanf` (может вернуть `EOF` или `0`). Если нужно — добавить проверку `if (fscanf(...) != 1) break;` с пометкой `// добавлено по правилам базы`.]
```
