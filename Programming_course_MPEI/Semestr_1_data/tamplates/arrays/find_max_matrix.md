
### Поиск максимума в матрице
**Источник:** `Пример лекции 8-9.docx`, функция `FindMax`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
void FindMax(float **z, int nx, int *imax, int *jmax)
{
    float Max=z[0][0];
    *imax=0;
    *jmax=0;
    for (int i=0; i<nx; i++)
    {
        for (int j=0; j<nx; j++)
        {
            if (Max<z[i][j])
            {
                Max=z[i][j];
                *imax=i;
                *jmax=j;
            }
        }
    }
    return;
}
```

**Ключевые особенности стиля:**
- `Max` — с заглавной
- `*imax=0;` — без пробелов вокруг `=` (сохранить)
- `if (Max<z[i][j])` — без пробелов вокруг `<`
- `return;` в конце `void`-функции — **обязательно** (стиль преподавателя)

**Частые ошибки преподавателя (опечатки):**
- `int& imax` (C++) → `int *imax` (C)
