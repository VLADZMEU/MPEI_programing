
### Сумма элементов вектора
**Источник:** `Пример лекции 8-9.docx`, функция `Sum`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
float Sum(float *x, int nx)
{
    float s=0.0;
    for (int i=0; i<nx;i++)
    {
        s+=x[i];
    }
    return s;
}
```

**Ключевые особенности стиля:**
- Имя функции `Sum` — с заглавной (CamelCase)
- `float s=0.0;` — инициализация `0.0` (не `0`)
- `for (int i=0; i<nx;i++)` — без пробела после `;` в третьей части
- Фигурные скобки на новой строке
- Нет `return;` (функция возвращает `float`, не `void`)

**Частые ошибки преподавателя (опечатки):**
- Нет (код корректен)
```

Пометка `[ИСПРАВЛЕНО ДИАЛЕКТ]` в заголовке может быть избыточной для этой функции — если в docx код уже был на C, убрать пометку.]

[ТРЕБУЕТ ПРОВЕРКИ: в шаблоне нет проверки `x == NULL` / `nx > 0`. Если `x` пуст или `nx == 0` — цикл не выполнится, `s` останется `0.0` (корректно). Если нужно добавить защиту — пометить `// добавлено по правилам базы`.]
[ТРЕБУЕТ ПРОВЕРКИ: `s+=x[i];` — сокращённая запись `s = s + x[i];`. Это стиль преподавателя (сохранить). Если по правилам базы нужно писать полную форму — заменить с пометкой `// БЫЛО: s+=x[i] → СТАЛО: s = s + x[i]`.]
[ТРЕБУЕТ ПРОВЕРКИ: `float s=0.0;` — инициализация `0.0` (не `0`). Если в docx `0` — заменить с пометкой `// БЫЛО: 0.0 → СТАЛО: 0 (по стилю docx)`.]
```
