
### Поиск наличия (проверка условия)
**Источник:** `Пример лекции 8-9.docx`, функция `Check`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]`

**Шаблон кода:**
```c
#include <stdbool.h>                    // добавлено для bool (C99)

bool Check(float *x, int nx, float t)
{
    int i=0;
    bool fl=true;
    while(i<nx && fl)
    {
        if (x[i]<t) i++;
        else fl=false;
    }
    return fl;
}
```

**Ключевые особенности стиля:**
- `bool fl=true;` — флаг `fl` (не `flag`!)
- `while(i<nx && fl)` — без пробела после `while`
- `if (x[i]<t) i++;` — без пробелов вокруг `<`
- `else fl=false;` — без фигурных скобок (одна инструкция)
- `return fl;` — возврат флага

**Частые ошибки преподавателя (опечатки):**
- В оригинале `bool` (C++) — в C99 нужен `<stdbool.h>` (добавлено)
```
