
### Ввод одномерного массива с клавиатуры
**Источник:** `Пример ввода одномерного массива.docx`
**Диалект:** C (C99) — `[ИСПРАВЛЕНО ДИАЛЕКТ]` (оригинал на C++)

**Шаблон кода:**
```c
#include <stdio.h>
#include <stdlib.h>                     // добавлено для malloc/free

int main()
{
    int *A;
    int n;
    scanf("%i", &n);
    A = (int*)malloc(n * sizeof(int));  // БЫЛО: new int[n] → СТАЛО: malloc
    if (A == NULL) return 1;            // добавлено по правилам базы
    for (int i=0; i<n; i++)
        scanf("%i", &A[i]);
    for (int i=0; i<n; i++)
        printf("%i ", A[i]);
    free(A);                            // добавлено (в оригинале нет — утечка)
    return 0;
}
```

**Ключевые особенности стиля:**
- `%i` для `int` (не `%d`!)
- `printf("%i ", A[i])` — пробел после `%i` в формате
- Циклы без фигурных скобок (одна инструкция) — сохранить
- `return 0;` в конце `main`

**Частые ошибки преподавателя (опечатки):**
- `#include <iostream>` — C++-заголовок, удалить
- `new int[n]` — C++, заменить на `malloc`
- Нет `free(A)` — утечка, добавить
- Нет проверки `A == NULL` — добавить
