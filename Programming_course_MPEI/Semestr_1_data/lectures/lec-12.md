## 2. Текстовый vs двоичный формат (слайд 3)

| Формат | Определение |
|--------|-------------|
| **Текстовый** | Кодировка, сопоставляющая каждому визуальному символу специальный числовой код |
| **Двоичный (бинарный)** | Запись числа в двоичной (16-ричной) форме в байт непосредственно |

> **Для шаблонов:** текстовые файлы — `fprintf/fscanf`, `fgets/fputs`; бинарные — `fread/fwrite`.

## 3. Открытие файла: `fopen` (слайд 4)

### Оригинал (слайд 4) — **с ошибкой**

```c
FILE *fd=fopen(const char 'имя текстового файла', const char 'режим открытия')
```

> **Разбор ошибок:**
> 1. `const char '...'` — **одинарные кавычки** для строки недопустимы в C. Должно быть `const char *` (указатель на строку) и **двойные кавычки** для литералов.
> 2. Пропущена `;` в конце.
> 3. `const char` без `*` — это один символ, а не строка.

### Исправленный прототип

```c
FILE *fd = fopen(const char *filename, const char *mode);
```

### Режимы открытия (слайды 4–5)

| Режим | Описание |
|-------|----------|
| `"r"` | Открыть для чтения (текстовый) |
| `"w"` | Создать для записи (текстовый) |
| `"a"` | Дописать в конец (текстовый) |
| `"rb"` | Открыть двоичный для чтения |
| `"wb"` | Создать двоичный для записи |
| `"ab"` | Дописать в конец двоичного |
| `"r+"` | Чтение/запись (текстовый) |
| `"w+"` | Создать для чтения/записи (текстовый) |
| `"a+"` | Дописать или создать для чтения/записи (текстовый) |
| `"r+b"` | Двоичный для чтения/записи |
| `"w+b"` | Создать двоичный для чтения/записи |
| `"a+b"` | Дописать или создать двоичный для чтения |
| `"rt"` | Текстовый для чтения |
| `"wt"` | Текстовый для записи |
| `"at"` | Дописать в конец текстового |
| `"r+t"` | Текстовый для чтения/записи |
| `"w+t"` | Создать текстовый для чтения/записи |
| `"a+t"` | Открыть/создать текстовый для чтения/записи |

> **Примечание:** `"r"` и `"rt"` эквивалентны; `"rb"` — бинарный (в Windows важно, в Linux почти нет разницы).

## 5. Чтение из файла (слайд 7)

```c
fread(&<переменная>, sizeof(<тип>), <количество>, <файл>);
```

> **Для шаблонов:** 
> - `&<переменная>` — адрес буфера
> - `sizeof(<тип>)` — размер одного элемента
> - `<количество>` — сколько элементов прочитать
> - `<файл>` — `FILE *`
> - Возвращает число прочитанных элементов (проверять на равенство ожидаемому)

## 7. Движение по файлу: `fseek` (слайд 9)

```c
int fseek(FILE *stream, long int offset, int origin);
```

| Константа | Значение |
|-----------|----------|
| `SEEK_SET` | Начало файла |
| `SEEK_CUR` | Текущее положение |
| `SEEK_END` | Конец файла (работает нестабильно — конец стандартом не определён) |

> **Примечание:** в оригинале `FILE * <файл>` — с пробелом, но это стилистика, не ошибка.

## 8. Определение позиции (слайд 10)

```c
int fgetpos(FILE *stream, fpos_t *pos);   // назначить pos текущее положение
int fsetpos(FILE *stream, const fpos_t *pos);  // перевести указатель в pos
long int ftell(FILE *stream);             // текущее положение от начала
```

- `fgetpos` / `fsetpos` возвращают `0` при успехе
- `ftell` для бинарных — число байт; для текстовых — не определено (но если однобайтовые символы — тоже байты)

## 9. Двухпутевое слияние (слайды 11–14)

### Код (слайды 11–14) — **с ошибками и обрезанными строками**

```c
// ОРИГИНАЛ (слайды 11–14) — с ошибками
void merge(int *a, int n) 
{ 
int mid = n / 2; // находим середину сортируемой последовательности 
if (n % 2 == 1) 
mid++; 
int h = 1; // шаг 
// выделяем память под формируемую последовательность 
int *c = (int*)malloc(n * sizeof(int)); 
int step; 
while (h < n) 
{ 
step = h; 
int i = 0; // индекс первого пути 
int j = mid; // индекс второго пути 
int k = 0; // индекс элемента в результирующей последовательности 
while (step <= mid) 
{ 
while ((i < step) && (j < n) && (j < (mid + step))) 
{ // пока не дошли до конца пути 
// заполняем следующий элемент формируемой последовательности 
// меньшим из двух просматриваемых
if (a[i] < a[j]) 
{ 
c[k] = a[i]; 
i++; k++; 
} 
else { 
c[k] = a[j]; 
j++; k++; 
} 
} 
while (i < step) 
{ 
// переписываем оставшиеся элементы первого пути (если второй кончился раньше)
c[k] = a[i]; 
i++; k++; 
} 
while ((j < (mid + step)) && (j<n)) 
{ // переписываем оставшиеся элементы второго пути (если первый кончился раньше) 
c[k] = a[j]; 
j++; k++; 
} 
step = step + h; // переходим к следующему этапу 
} 
h = h * 2; 
// Переносим упорядоченную последовательность (промежуточный вариант) в исходный массив 
for (i = 0; i<n; i++) 
a[i] = c[i]; 
} 
}
```

> **Разбор ошибок и проблем:**
> 1. **Не хватает `#include <stdlib.h>`** для `malloc`.
> 2. **Не проверяется `c == NULL`** после `malloc`.
> 3. **Утечка памяти:** нет `free(c);` в конце функции. 
> 4. **Несогласованность индексов:** `i = 0`, `j = mid`, но `mid = n/2` (при нечётном `n` — `mid++`). Логика может быть верной, но требует проверки.
> 5. **`step = step + h;`** — эквивалентно `step += h;` (не ошибка, стиль).
> 6. **Слайд 14 обрывается:** после `a[i] = c[i]; } }` — не хватает `free(c);` перед закрывающей скобкой функции.
> 7. **Форматирование:** в слайдах код без отступов (плохо читается), но это стиль лекции.

### Исправленный шаблон (для базы знаний) — **с добавленной проверкой и free**

```c
#include <stdlib.h>

void merge(int *a, int n) 
{ 
    int mid = n / 2; 
    if (n % 2 == 1) 
        mid++; 
    int h = 1; 
    int *c = (int*)malloc(n * sizeof(int)); 
    if (c == NULL) return;          // добавлено по правилам базы (в лекции отсутствует)
    int step; 
    while (h < n) 
    { 
        step = h; 
        int i = 0; 
        int j = mid; 
        int k = 0; 
        while (step <= mid) 
        { 
            while ((i < step) && (j < n) && (j < (mid + step))) 
            { 
                if (a[i] < a[j]) 
                { 
                    c[k] = a[i]; 
                    i++; k++; 
                } 
                else { 
                    c[k] = a[j]; 
                    j++; k++; 
                } 
            } 
            while (i < step) 
            { 
                c[k] = a[i]; 
                i++; k++; 
            } 
            while ((j < (mid + step)) && (j<n)) 
            { 
                c[k] = a[j]; 
                j++; k++; 
            } 
            step = step + h; 
        } 
        h = h * 2; 
        for (i = 0; i<n; i++) 
            a[i] = c[i]; 
    } 
    free(c);                        // добавлено (в лекции отсутствует — утечка)
}
```

> **Особенности стиля:**
> - `i`, `j`, `k` — индексы путей
> - `mid` — середина
> - `h` — шаг
> - `step` — текущий шаг
> - `c` — временный массив
> - Комментарии на русском (сохранить)

## 10. Нисходящее слияние (слайды 15–16)

### Код (слайды 15–16) — **с ошибками**

```c
// ОРИГИНАЛ (слайды 15–16) — с ошибками
void mergeSort(int *a, int l, int r)
{
if (l == r) return; 
int mid = (l + r) / 2; 
mergeSort(a, l, mid);
mergeSort(a, mid + 1, r);
int i = l; 
int j = mid + 1; 
int *tmp = (int*)malloc(r * sizeof(int));  // ❌ БЫЛО: r → СТАЛО: r - l + 1 (или (r+1))
```

> **Разбор ошибок:**
> 1. **`malloc(r * sizeof(int))`** — выделяет `r` элементов, но нужно `r - l + 1` (длина подмассива). Если `l > 0`, это может быть меньше нужного → **выход за границы**. 
>    > **Исправление:** `malloc((r - l + 1) * sizeof(int))`.
> 2. **Не проверяется `tmp == NULL`**.
> 3. **Нет `free(tmp)`** в конце функции.
> 4. **Слайд 16 содержит `java` в блоке кода** (опечатка разметки, не влияет на C-код).
> 5. **Не хватает `#include <stdlib.h>`**.

### Исправленный шаблон (для базы знаний)

```c
#include <stdlib.h>

void mergeSort(int *a, int l, int r)
{
    if (l == r) return; 
    int mid = (l + r) / 2; 
    mergeSort(a, l, mid);
    mergeSort(a, mid + 1, r);
    int i = l; 
    int j = mid + 1; 
    int *tmp = (int*)malloc((r - l + 1) * sizeof(int));  // БЫЛО: r → СТАЛО: r - l + 1
    if (tmp == NULL) return;          // добавлено
    for (int step = 0; step < r - l + 1; step++) 
    {
        if ((j > r) || ((i <= mid) && (a[i] < a[j])))
        {
            tmp[step] = a[i];
            i++;
        }
        else
        {
            tmp[step] = a[j];
            j++;
        }
    }
    for (int step = 0; step < r - l + 1; step++)
        a[l + step] = tmp[step];
    free(tmp);                        // добавлено
}
```

## 11. Восходящее слияние (слайды 17–18)

### Код (слайды 17–18) — **с ошибками**

```c
// ОРИГИНАЛ (слайды 17–18) — с ошибками
void mergeSort(int *a, int n)
{
int step = 1; 
int *temp = (int*)malloc(n * sizeof(int));  // ❌ нет проверки NULL
while (step < n) 
{
int index = 0; 
int l = 0; 
int m = l + step; 
int r = l + step * 2; 
do
{
m = m < n ? m : n; 
r = r < n ? r : n;
int i1 = l, i2 = m; 
for (; i1 < m && i2 < r; ) 
{
if (a[i1] < a[i2]) { temp[index++] = a[i1++]; } 
else { temp[index++] = a[i2++]; }
} 
while (i1 < m) temp[index++] = a[i1++]; 
while (i2 < r) temp[index++] = a[i2++]; 
l += step * 2; 
m += step * 2; 
r += step * 2; 
} while (l < n); 
for (int i = 0; i < n; i++) 
a[i] = temp[i]; 
step *= 2; 
}
```

> **Разбор ошибок:**
> 1. **Не проверяется `temp == NULL`**.
> 2. **Нет `free(temp)`** в конце функции.
> 3. **Не хватает `#include <stdlib.h>`**.
> 4. **Слайд 18 содержит обрывки текста** («resultующей», «сортируемых участков») — это опечатки в комментариях, не влияют на код.
> 5. **Форматирование:** нет отступов (плохо читается), но это стиль лекции.
> 6. **Логика:** вроде корректна (восходящее слияние), но `m = l + step` — если `l` меняется, `m` и `r` пересчитываются. В оригинале `m += step * 2` и `r += step * 2` — эквивалентно.

### Исправленный шаблон (для базы знаний)

```c
#include <stdlib.h>

void mergeSort(int *a, int n)
{
    int step = 1; 
    int *temp = (int*)malloc(n * sizeof(int)); 
    if (temp == NULL) return;          // добавлено
    while (step < n) 
    {
        int index = 0; 
        int l = 0; 
        int m = l + step; 
        int r = l + step * 2; 
        do
        {
            m = m < n ? m : n; 
            r = r < n ? r : n;
            int i1 = l, i2 = m; 
            for (; i1 < m && i2 < r; ) 
            {
                if (a[i1] < a[i2]) { temp[index++] = a[i1++]; } 
                else { temp[index++] = a[i2++]; }
            } 
            while (i1 < m) temp[index++] = a[i1++]; 
            while (i2 < r) temp[index++] = a[i2++]; 
            l += step * 2; 
            m += step * 2; 
            r += step * 2; 
        } while (l < n); 
        for (int i = 0; i < n; i++) 
            a[i] = temp[i]; 
        step *= 2; 
    } 
    free(temp);                        // добавлено
}
```

## Ключевые выводы для `templates/files/`

1. **Открытие файла:**
   ```c
   FILE *fd = fopen(const char *filename, const char *mode);
   if (fd == NULL) { /* обработка ошибки */ }
   ```
2. **Закрытие:** `fclose(fd);`
3. **Бинарный файл:** режимы `"rb"`, `"wb"`, `"ab"`, `"r+b"`, `"w+b"`, `"a+b"`
4. **Чтение:** `fread(&var, sizeof(type), count, fd);`
5. **Запись:** `fwrite(&var, sizeof(type), count, fd);`
6. **Позиционирование:** `fseek(fd, offset, SEEK_SET/SEEK_CUR/SEEK_END);`, `ftell(fd);`
7. **Типичные опечатки преподавателя (исправлять с пометкой):**
   - `const char '...'` → `const char *` + двойные кавычки
   - `malloc(r * sizeof(int))` → `malloc((r - l + 1) * sizeof(int))`
   - Отсутствие проверки `NULL` после `malloc`
   - Отсутствие `free`
   - Отсутствие `#include <stdlib.h>`
8. **Сортировка слиянием** — отдельная тема, шаблоны в `templates/arrays/` (не `files/`)
