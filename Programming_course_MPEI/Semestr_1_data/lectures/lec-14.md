## 1. Определение структуры (слайды 2–3)

> **Структура** — это объединение нескольких объектов, возможно, различного типа под одним именем, которое является типом структуры. В качестве объектов могут выступать переменные, массивы, указатели и другие структуры.

{
    тип ИмяЭлемента1;
    тип ИмяЭлемента2;
    ...
    тип ИмяЭлементаn;
};
```

> **Примечание:** в C после `}` нужна `;`. В слайде она есть — ✅.

## 3. Инициализация структуры (слайд 5) — **с ошибкой (неполный код)**

### Оригинал (слайд 5)

```c
struct date bd={8,"июня", 1978};
```

> **Разбор:** нет объявления `struct date` перед инициализацией. Должно быть:
> ```c
> struct date {
>     int day;
>     char month[20];
>     int year;
> };
> struct date bd = {8, "июня", 1978};
> ```

### Исправленный шаблон

```c
struct date {
    int day;
    char month[20];
    int year;
};

struct date bd = {8, "июня", 1978};
```

## 5. Создание типа через `typedef` (слайд 7) — **с C++-вкраплением**

### Оригинал (слайд 7)

```c
typedef struct
{
    int age;
    char* name;
} person;

int main(void)
{
    person tom = {23, "Tom"};
    printf("Name:%s \t Age: %d", tom.name, tom.age);
    return 0;
}
```

> **Разбор:**
> 1. `char* name` — указатель на `char`. В C допустимо, но **опасно**: если `name` указывает на литерал `"Tom"` (read-only), попытка изменить строку — UB. Для шаблонов безопаснее `char name[20];`.
> 2. `person tom = {23, "Tom"};` — инициализация структуры. В C корректно (агрегатная инициализация).
> 3. Нет `#include <stdio.h>` для `printf`.
> 4. `%d` для `int` — в стиле преподавателя `%i` (но в этом слайде `%d` — сохранить как есть, т.к. это оригинал).

### Исправленный шаблон

```c
#include <stdio.h>

typedef struct
{
    int age;
    char name[20];   // БЫЛО: char* name → СТАЛО: char name[20] (безопаснее)
} person;

int main(void)
{
    person tom = {23, "Tom"};
    printf("Name:%s \t Age: %d", tom.name, tom.age);
    return 0;
}
```

## 6. Описание структуры через `#define` (слайд 8)

### Оригинал (слайд 8)

```c
#include <stdio.h>
#define PERSON struct {int age; char name[20];}
int main(void)
{
    PERSON tom = {23, "Tom"};
    printf("Name:%s \t Age: %d", tom.name, tom.age);
    return 0;
}
```

> **Примечание:** `#define PERSON struct {...}` — макрос, разворачивающийся в анонимную структуру. Работает, но **не рекомендуется** (нет типа для повторного использования). Для шаблонов — использовать `typedef struct` (слайд 7).

## 7. Структура в структуре (слайд 9) — **с ошибкой (нет `struct` перед `date`)**

### Оригинал (слайд 9)

```c
struct date
{
    int day;
    char month[20];
    int year;
};
struct persone
{
    char firstname[20];
    char lastname[20];
    date bd;
};
```

> **Разбор:**
> 1. `date bd;` — **ошибка**: в C нужно `struct date bd;` (если нет `typedef`). В C++ можно без `struct`.
> 2. `persone` — опечатка? Вероятно, `person` (но сохранить как в оригинале — стиль преподавателя).

### Исправленный шаблон

```c
struct date
{
    int day;
    char month[20];
    int year;
};
struct persone
{
    char firstname[20];
    char lastname[20];
    struct date bd;   // БЫЛО: date bd → СТАЛО: struct date bd
};
```

## 9. Объединения — определение (слайды 12–13)

> **Объединениями** называют сложный тип данных, позволяющий размещать в одном и том же месте оперативной памяти данные различных типов.

## 10. Объявление объединения (слайд 14)

### Оригинал (слайд 14) — **с опечаткой (нет `;`)**

```c
union ИмяОбъединения  {  тип ИмяОбъекта1;  тип ИмяОбъекта2;  . . .  тип ИмяОбъектап;  }
```

> **Разбор:** пропущена `;` после `}`. Должно быть `};`.

### Исправленный шаблон

```c
union ИмяОбъединения
{
    тип ИмяОбъекта1;
    тип ИмяОбъекта2;
    ...
    тип ИмяОбъектаn;
};
```

---

## 11. Применение объединений (слайд 15)

Объединения применяются для следующих целей:
- для инициализации объекта, если в каждый момент времени только один из многих объектов является активным;
- для интерпретации представления одного типа данных в виде другого типа.

## 12. Пример использования объединений (слайд 16) — **с C++-вкраплением (`types value;` без `union`)**

### Оригинал (слайд 16)

```c
#include <stdio.h>
#include <stdlib.h>
union types
{
    float f;
    unsigned char b[4];
};
int main()
{
    types value;
    printf("N = ");
    scanf("%f", &value.f);
    printf("%f = %x %x %x %x", value.f, value.b[0], value.b[1], value.b[2], value.b[3]);
    getchar();
    getchar();
    return 0;
}
```

> **Разбор:**
> 1. `types value;` — **ошибка**: в C нужно `union types value;` (если нет `typedef`). В C++ можно без `union`.
> 2. `%x` для `unsigned char` — **некорректно**: `%x` ожидает `unsigned int`, а `unsigned char` продвигается до `int`. Для `unsigned char` правильно `%hhx` (C99) или явное приведение `(unsigned int)value.b[0]`.
> 3. `getchar(); getchar();` — пауза (ожидание ввода). Стиль преподавателя — сохранить.
> 4. `scanf("%f", &value.f)` — корректно.

### Исправленный шаблон

```c
#include <stdio.h>
#include <stdlib.h>
union types
{
    float f;
    unsigned char b[4];
};
int main()
{
    union types value;   // БЫЛО: types value → СТАЛО: union types value
    printf("N = ");
    scanf("%f", &value.f);
    printf("%f = %x %x %x %x", value.f, (unsigned int)value.b[0], (unsigned int)value.b[1], (unsigned int)value.b[2], (unsigned int)value.b[3]);  // БЫЛО: value.b[0] → СТАЛО: (unsigned int)value.b[0]
    getchar();
    getchar();
    return 0;
}
```

## 13. Массивы структур — создание типа (слайд 18)

### Оригинал (слайд 18)

```c
struct ИмяСтруктуры
{
    тип ИмяЭлемента1;
    тип ИмяЭлемента2;
    ...
    тип ИмяЭлементап;
};
 
ИмяСтруктуры ИмяМассива[кол-во]; 
ИмяСтруктуры *ИмяМассива;
```

> **Разбор:**
> 1. `ИмяСтруктуры ИмяМассива[кол-во];` — **ошибка**: в C нужно `struct ИмяСтруктуры ИмяМассива[кол-во];` (если нет `typedef`).
> 2. `ИмяСтруктуры *ИмяМассива;` — аналогично, нужно `struct ИмяСтруктуры *ИмяМассива;`.

### Исправленный шаблон

```c
struct ИмяСтруктуры
{
    тип ИмяЭлемента1;
    тип ИмяЭлемента2;
    ...
    тип ИмяЭлементаn;
};

struct ИмяСтруктуры ИмяМассива[кол-во];   // БЫЛО: ИмяСтруктуры ИмяМассива → СТАЛО: struct ИмяСтруктуры ИмяМассива
struct ИмяСтруктуры *ИмяМассива;           // БЫЛО: ИмяСтруктуры *ИмяМассива → СТАЛО: struct ИмяСтруктуры *ИмяМассива
```

## 14. Пример массива структур (слайд 19) — **с C++-вкраплением (`book library[3];` без `struct`)**

### Оригинал (слайд 19)

```c
struct book
{
    char title[15];
    char author[15];
    int value;
};
int main()
{
    book library[3];
    int i;
    system("chcp 1251");
    system("cls");
}
```

> **Разбор:**
> 1. `book library[3];` — **ошибка**: в C нужно `struct book library[3];` (если нет `typedef`).
> 2. `system("chcp 1251"); system("cls");` — Windows-специфичные команды (смена кодировки на 1251, очистка экрана). Стиль преподавателя — сохранить.
> 3. Нет `#include <stdlib.h>` для `system`.
> 4. `main` без `return 0;` — слайд обрывается, продолжение на слайде 20.

### Исправленный шаблон

```c
#include <stdio.h>
#include <stdlib.h>   // добавлено для system()

struct book
{
    char title[15];
    char author[15];
    int value;
};
int main()
{
    struct book library[3];   // БЫЛО: book library[3] → СТАЛО: struct book library[3]
    int i;
    system("chcp 1251");
    system("cls");
    return 0;                 // добавлено (слайд обрывается)
}
```

## 15. Пример массива структур — ввод/вывод (слайд 20) — **с ошибками**

### Оригинал (слайд 20)

```c
for (i = 0; i<3; i++)
{
    printf("Введите название %d книги : ", i + 1);
    gets_s(library[i].title);
    printf("Введите автора %d книги : ", i + 1);
    gets_s(library[i].author);
    printf("Введите цену %d книги : ", i + 1);
    scanf_s("%d", &library[i].value);
    getchar();
}
for (i = 0; i<3; i++)
{
    printf("\n %d. %s ", i + 1, library[i].author);
    printf("%s %d", library[i].title, library[i].value);
}
getchar();
return 0;
```

> **Разбор:**
> 1. `gets_s` — **C11 Annex K** (небезопасная функция, доступна не везде). В стандартном C — `fgets`. Стиль преподавателя — сохранить `gets_s` с пометкой.
> 2. `scanf_s("%d", ...)` — **C11 Annex K** (аналог `scanf` с контролем размера для строк). Для `%d` размер не нужен, но `scanf_s` может требовать его для `%s`/`%c`. Стиль преподавателя — сохранить.
> 3. `getchar();` после `scanf_s` — съедает `\n` после ввода числа. Стиль преподавателя — сохранить.
> 4. `%d` для `int` — в стиле преподавателя `%i` (но в этом слайде `%d` — сохранить как есть).
> 5. Нет `#include <stdio.h>` и `#include <stdlib.h>` (но они подразумеваются из слайда 19).

### Исправленный шаблон

```c
// ... продолжение из слайда 19 ...
for (i = 0; i<3; i++)
{
    printf("Введите название %d книги : ", i + 1);
    gets_s(library[i].title);          // C11 Annex K — сохранить (стиль преподавателя)
    printf("Введите автора %d книги : ", i + 1);
    gets_s(library[i].author);         // C11 Annex K — сохранить
    printf("Введите цену %d книги : ", i + 1);
    scanf_s("%d", &library[i].value);  // C11 Annex K — сохранить
    getchar();
}
for (i = 0; i<3; i++)
{
    printf("\n %d. %s ", i + 1, library[i].author);
    printf("%s %d", library[i].title, library[i].value);
}
getchar();
return 0;
```

> **Альтернатива без Annex K** (если компилятор не поддерживает `gets_s`/`scanf_s`):
> ```c
> fgets(library[i].title, 15, stdin);   // вместо gets_s
> fgets(library[i].author, 15, stdin);  // вместо gets_s
> scanf("%d", &library[i].value);       // вместо scanf_s
> ```
