## 1. Вложенные циклы (слайд 2) — **с ошибкой**

### Оригинал (слайд 2)

```c
for (int i=0; i<5; i++)
    for (int j=0; j<5; j++)
        printf("%2d %2d", i, j);
    printf("\n")
```

> **Разбор ошибок:**
> 1. Пропущена `;` после `printf("\n")`.
> 2. **Логическая ошибка отступов:** `printf("\n")` должен выполняться **после внутреннего цикла**, но **внутри внешнего** (чтобы переводить строку после каждой строки матрицы). В оригинале он вне обоих циклов (из-за отступа) — тогда перевода строки после каждой строки не будет.
> 3. `printf("%2d %2d", i, j)` — выводит индексы, а не элементы матрицы. Для шаблона матрицы нужно `printf("%2d ", A[i][j]);`.

### Исправленный шаблон (для базы знаний)

```c
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        printf("%2d %2d", i, j);    // для вывода индексов
        // или для вывода элементов матрицы:
        // printf("%2d ", A[i][j]);
    }
    printf("\n");                   // БЫЛО: printf("\n") → СТАЛО: printf("\n");
}                                   // БЫЛО: без скобок → СТАЛО: с фигурными скобками
```

> **Особенности стиля:**
> - `%2d` — формат с шириной 2 (выравнивание)
> - Вложенные циклы `i` (строки), `j` (столбцы)
> - `printf("\n")` после внутреннего цикла

## 2. Матрица: динамическое выделение (слайд 3) — **с ошибками**

### Оригинал (слайд 3)

```c
float **A; 
A = (int**)malloc(n * sizeof(int*)); 
for (int i = 0; i < n; i++){ 
A[i] = (int*)malloc(m * sizeof(int)); 
for (int j=0; j<m; j++) { 
scanf("%f", &A[i][j]); 
} 
}
```

> **Разбор ошибок:**
> 1. **Несоответствие типов:** `A` объявлена как `float**`, но `malloc` выделяет `int*` и `int`. Для `float` нужно `(float**)malloc(n * sizeof(float*))` и `(float*)malloc(m * sizeof(float))`.
> 2. **Не проверяется `NULL`** после `malloc` (ни для `A`, ни для `A[i]`).
> 3. **Нет `free`** — утечка памяти.
> 4. **Не хватает `#include <stdlib.h>`** для `malloc`.
> 5. **Формат `scanf("%f", ...)`** — корректен для `float`.

### Исправленный шаблон (для базы знаний)

```c
#include <stdio.h>
#include <stdlib.h>

float **A;
A = (float**)malloc(n * sizeof(float*));           // БЫЛО: (int**)malloc(n * sizeof(int*)) → СТАЛО: (float**)malloc(n * sizeof(float*))
if (A == NULL) return 1;                           // добавлено по правилам базы
for (int i = 0; i < n; i++){
    A[i] = (float*)malloc(m * sizeof(float));       // БЫЛО: (int*)malloc(m * sizeof(int)) → СТАЛО: (float*)malloc(m * sizeof(float))
    if (A[i] == NULL) return 1;                    // добавлено по правилам базы
    for (int j=0; j<m; j++) {
        scanf("%f", &A[i][j]);
    }
}
// ... работа с матрицей ...
free(A);                                            // добавлено (в оригинале нет — утечка)
```

> **Особенности стиля:**
> - `n` — число строк, `m` — число столбцов
> - `scanf("%f", &A[i][j])` — ввод элементов
> - `float**` — матрица как массив указателей

## 5. Квадратная матрица: диагонали и области (слайд 6)

| Область | Код |
|---------|-----|
| **Главная диагональ** | `for (int i=0; i<n; i++) s+=x[i][i]` |
| **Побочная диагональ** | `for (int i=0; i<n; i++) s+=x[i][n-i-1]` |
| **Над главной диагональю** | `for (int i=0; i<n; i++) for (int j=i+1; j<n; j++) s+=x[i][j]` |
| **Над побочной диагональю** | `for (int i=0; i<n; i++) for (int j=0; j<n-i; j++) s+=x[i][j]` |
| **Под главной диагональю** | `for (int i=0; i<n; i++) for (int j=0; j<i; j++) s+=x[i][j]` |
| **Под побочной диагональю** | `for (int i=0; i<n; i++) for (int j=n-i+1; j<n; j++) s+=x[i][j]` |

> **Примечание:** код в слайде без `;` после `s+=x[i][j]` — это фрагменты, не полные операторы. Для шаблонов добавить `;`.

## 6. Прямоугольная матрица: половины (слайд 7)

| Область | Код |
|---------|-----|
| **Левая половина** | `for (int i=0; i<n; i++) for (int j=0; j<m/2; j++) s+=x[i][j]` |
| **Правая половина** | `for (int i=0; i<n; i++) for (int j=m/2; j<m; j++) s+=x[i][j]` |
| **Верхняя половина** | `for (int i=0; i<n/2; i++) for (int j=0; j<m; j++) s+=x[i][j]` |
| **Нижняя половина** | `for (int i=n/2+1; i<n; i++) for (int j=0; j<m; j++) s+=x[i][j]` |

> **Примечание:** в оригинале (слайд 7) код без `;` после `s+=x[i][j]` — это фрагменты. Для шаблонов добавить `;`.

## 7. Упорядочивание (сортировка пузырьком) (слайд 8) — **с ошибками**

### Оригинал (слайд 8)

```c
fl=True;
k=1;
while (fl && k<n){
    fl=False;
    for (int i=0; i<n-k; i++){
        if (A[i]>A[i+1]){
            fl=True;
            buf=A[i];
            A[i]=A[i+1];
            A[i+1]=buf;}
    }
    k+=1;}
```

> **Разбор ошибок:**
> 1. `fl=True` — Python-синтаксис. В C: `true` (C99, `<stdbool.h>`) или `1`.
> 2. `fl=False` — аналогично.
> 3. `fl=True` — аналогично.
> 4. Не хватает `#include <stdbool.h>` (если использовать `bool`/`true`/`false`).
> 5. `buf` не объявлена — нужно объявить заранее (`int buf;` или `float buf;`).

### Исправленный шаблон (для базы знаний)

```c
#include <stdbool.h>

bool fl = true;                             // БЫЛО: fl=True → СТАЛО: bool fl = true
int k = 1;
int buf;                                    // добавлено (в оригинале не объявлена)
while (fl && k<n){
    fl = false;                             // БЫЛО: fl=False → СТАЛО: fl = false
    for (int i=0; i<n-k; i++){
        if (A[i]>A[i+1]){
            fl = true;                      // БЫЛО: fl=True → СТАЛО: fl = true
            buf=A[i];
            A[i]=A[i+1];
            A[i+1]=buf;
        }
    }
    k+=1;
}
```

> **Особенности стиля:**
> - `fl` — флаг (не `flag`!)
> - `k` — счётчик проходов
> - `buf` — временная переменная для обмена
> - Сортировка пузырьком (оптимизированная: `k<n` — не более `n` проходов)

## 8. Транспонирование (слайд 9)

### Оригинал (слайд 9)

```c
for (int i=0; i<n; i++) 
for (int j=i+1; j<n; j++){ 
buf=A[i][j]; 
A[i][j]=A[j][i]; 
A[j][i]=buf;}
```

> **Примечание:** `buf` не объявлена — нужно объявить заранее (`float buf;`). Логика корректна (обмен `A[i][j]` ↔ `A[j][i]` для `j > i`).

### Исправленный шаблон (для базы знаний)

```c
float buf;                                  // добавлено (в оригинале не объявлена)
for (int i=0; i<n; i++) 
    for (int j=i+1; j<n; j++){ 
        buf=A[i][j]; 
        A[i][j]=A[j][i]; 
        A[j][i]=buf;
    }
```

> **Особенности стиля:**
> - Транспонирование квадратной матрицы `n×n`
> - `j=i+1` — обмен только для верхнего треугольника (иначе обмен дважды)

## 9. Циклический сдвиг влево (слайд 10)

### Оригинал (слайд 10)

```c
buf=A[0]; 
for (int i=0; i<n-1; i++) 
A[i]=A[i+1]; 
A[n-1]=buf;
```

> **Примечание:** `buf` не объявлена — нужно объявить заранее. Логика корректна (сохранить первый элемент, сдвинуть все влево, поставить сохранённый в конец).

### Исправленный шаблон (для базы знаний)

```c
float buf;                                  // добавлено (в оригинале не объявлена)
buf=A[0]; 
for (int i=0; i<n-1; i++) 
    A[i]=A[i+1]; 
A[n-1]=buf;
```

> **Особенности стиля:**
> - Циклический сдвиг одномерного массива влево на 1
> - `buf` — временная переменная

## 10. Циклический сдвиг вправо (слайд 11) — **с ошибкой**

### Оригинал (слайд 11)

```c
buf=A[n-1]; 
for (int i=n-1; i>1; i--) 
A[i]=A[i-1]; 
A[0]=buf;
```

> **Разбор ошибки:**
> 1. `i>1` — **логическая ошибка**: должно быть `i>0`, иначе элемент `A[1]` не сдвинется (останется `A[0]` на месте `A[1]`).
> 2. `buf` не объявлена — нужно объявить заранее.

### Исправленный шаблон (для базы знаний)

```c
float buf;                                  // добавлено (в оригинале не объявлена)
buf=A[n-1]; 
for (int i=n-1; i>0; i--)                   // БЫЛО: i>1 → СТАЛО: i>0
    A[i]=A[i-1]; 
A[0]=buf;
```

> **Особенности стиля:**
> - Циклический сдвиг одномерного массива вправо на 1
> - `buf` — временная переменная
