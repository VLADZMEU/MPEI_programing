## 1. Модульное программирование (слайд 2)

### Определение
> **Модульное программирование** — система из небольших независимых блоков (модулей), структура и поведение которых подчиняются определённым правилам.

### Три ключевых принципа

| Принцип | Суть | C-реализация |
|---------|------|--------------|
| **Единообразие синтаксиса и структуры** | Единый стиль кода | Одинаковые отступы, имена, форматирование |
| **Автономность** | Максимальная локализация переменных и функций | `static` для функций и глобальных переменных внутри файла |
| **Сокрытие имён** | Механизмы сокрытия от других модулей | `static` + разделение на `.h` / `.c` |

## 2. Как это выглядит в C (дополнение для базы знаний)

> **Примечание:** в лекции нет кода. Ниже — стандартный C-эквивалент для будущих шаблонов (на основе стандарта C, не из лекции).

### Структура модуля
```
module.h   — заголовочный файл (интерфейс, прототипы)
module.c   — реализация (определения функций)
main.c     — главный файл (подключает module.h)
```

### Пример: `math_utils.h`
```c
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

int add(int a, int b);
int sub(int a, int b);

#endif
```

### Пример: `math_utils.c`
```c
#include "math_utils.h"

// static — функция видна только внутри этого файла (сокрытие)
static int is_valid(int x) {
    return x != 0;
}

int add(int a, int b) {
    return a + b;
}

int sub(int a, int b) {
    if (!is_valid(a)) return 0;
    return a - b;
}
```

### Пример: `main.c`
```c
#include <stdio.h>
#include "math_utils.h"

int main() {
    printf("%d\n", add(2, 3));
    printf("%d\n", sub(5, 2));
    return 0;
}
```

> **Для шаблонов:** если в docx-примерах есть модульная структура — использовать её стиль (имена файлов, `#ifndef` guard, порядок `#include`). Если нет — **не генерировать модули без явного запроса**.
