## 2. Свойства алгоритма (слайд 3)

1. **Дискретность** — разбиение на отдельные шаги
2. **Детерминированность** — однозначность результата при одинаковых входных данных
3. **Понятность** — алгоритм понятен исполнителю
4. **Завершаемость (конечность)** — конечное число шагов
5. **Массовость** — применимость к классу задач
6. **Результативность** — получение результата

## 3. Способы описания алгоритма (слайд 4)

- Словесный
- Формульно-словесный
- Табличный
- Графический (блок-схемы)
- Программный ← **основной для нас**

## 4. Элементы блок-схем (слайд 5)

| Фигура | Назначение |
|--------|-----------|
| Прямоугольник | Действие / процесс |
| Параллелограмм | Ввод/вывод |
| Прямоугольник с двойными стенками | Предопределённый процесс (вызов функции) |
| Скруглённый прямоугольник | Начало/конец |
| Ромб | Условие (ветвление) |
| Шестиугольник | Подготовка (цикл) |

## 5. Примеры участков блок-схем (слайд 6)

- **Линейный участок:** Действие 1 → Действие 2
- **Ветвление:** Условие → (да) Действие 1 / (нет) Действие 2
- **Цикл с предусловием:** Условие → (да) Действие → возврат к условию; (нет) выход

## 6. Методы программирования (слайд 7)

- **Нисходящий** (top-down) — от общего к частному
- **Восходящий** (bottom-up) — от частного к общему

## 7. Типы данных (слайд 8)

### Простые
- Целочисленные (`int`, `char`, `short`, `long`)
- Дробные числа (`float`, `double`)
- Символьные (`char`)
- Логические (`int` в C, `bool` в C99 через `<stdbool.h>`)
- Значения без типа (`void`)

### Составные
- Строки (в C — `char[]` / `char*`, класс `string` — **C++**, игнорируем)
- Массивы
- Ссылки (в C — **указатели**, `&`-ссылки — **C++**, игнорируем)
- Функции
- Пользовательские (`struct`, `union`, `enum`)
- Перечисляемые (`enum`)

> **[ИСПРАВЛЕНО ДИАЛЕКТ]** В лекции упомянут «класс string» и «ссылки» — это C++. В C используются `char*`/`char[]` и указатели.

## Ключевые выводы для базы знаний

1. **C — компилируемый, статически типизированный, процедурный** язык
2. В шаблонах использовать **только C-конструкции** (никаких классов, ссылок, `cin/cout`)
3. Преподаватель делает акцент на **блок-схемах** → в коде приветствуются комментарии, отражающие логику ветвлений/циклов
