## 1. Определение C (слайд 2)

> **Си** — компилируемый статически типизированный язык программирования общего назначения, разработанный в 1969–1973 годах сотрудником Bell Labs **Деннисом Ритчи** как развитие языка **Би (B)**.

**Ключевые атрибуты (для базы знаний):**
- Компилируемый (не интерпретируемый)
- Статически типизированный (тип известен на этапе компиляции)
- Общего назначения
- Процедурный (не ООП)

## 2. Основные особенности Си (слайды 3–4)

### 2.1 Простая языковая база
Многие существенные возможности вынесены в **стандартную библиотеку**:
- математические функции (`<math.h>`)
- функции работы с файлами (`<stdio.h>`)
- работа со строками (`<string.h>`)
- работа с памятью (`<stdlib.h>`)

> **Для шаблонов:** всегда выписывать `#include` для используемых библиотек.

### 2.2 Ориентация на процедурное программирование
- Программа = набор функций
- Нет классов, наследования, полиморфизма
- **Для шаблонов:** использовать `struct` + функции для работы с ними

### 2.3 Система типов, предохраняющая от бессмысленных операций
- Нельзя сложить указатель с `float` без явного приведения
- Нельзя присвоить `int*` в `char*` без приведения (в C — с предупреждением)
- **Для шаблонов:** явные приведения типов там, где это необходимо

### 2.4 Использование препроцессора
- `#define` для констант и макросов
- `#include` для подключения заголовков
- Условная компиляция (`#ifdef`, `#ifndef`, `#endif`)
- **Для шаблонов:** использовать `#define` для размеров массивов, если так принято в примерах

### 2.5 Доступ к памяти через указатели
- `*` — разыменование
- `&` — взятие адреса
- `malloc/free` — динамическое выделение/освобождение
- **Для шаблонов:** обязательно проверять `if (ptr == NULL)` после `malloc`

### 2.6 Небольшое число ключевых слов
(В C99 — 37 ключевых слов; в C11 — 44)

### 2.7 Передача параметров в функцию **по значению**
- Не по ссылке (в отличие от C++)
- Передача по ссылке эмулируется через **указатели**
- **Для шаблонов:** если функция должна изменить переменную — передавать `int*`, а не `int`

```c
// Пример: передача по указателю (C-стиль)
void increment(int *x) {
    (*x)++;
}
// Вызов:
int a = 5;
increment(&a);  // a станет 6
```

### 2.8 Указатели на функции и статические переменные
- Указатель на функцию: `int (*func_ptr)(int, int);`
- Статические переменные: `static int counter = 0;` (сохраняют значение между вызовами)
- **Для шаблонов:** использовать, если в примерах преподавателя есть

### 2.9 Области видимости имён
- Локальные (внутри функции/блока)
- Глобальные (вне функций)
- `static` на глобальном уровне — видимость только в пределах файла

### 2.10 Структуры и объединения
- `struct` — собирательный тип (поля хранятся вместе)
- `union` — поля разделяют одну область памяти
- **Для шаблонов:** `struct` — основной способ создания пользовательских типов в C

```c
// Пример структуры (C-стиль)
struct Point {
    int x;
    int y;
};
// Использование:
struct Point p;
p.x = 10;
p.y = 20;
```

> **В C++** можно писать `Point p;` без `struct`. **В C** нужно `struct Point p;` (или `typedef struct { ... } Point;`).

## 3. Чего **нет** в Си (слайд 5)

| Отсутствует | C-эквивалент / обходной путь |
|-------------|------------------------------|
| Вложенные функции | Вынести функцию на верхний уровень |
| Прямое возвращение нескольких значений | Вернуть `struct` или использовать указатели-параметры |
| Сопрограммы | Не эмулировать (нет стандартного механизма) |
| Автоматическое управление памятью | `malloc/free` вручную; проверять `NULL` |
| Встроенные средства ООП | `struct` + функции; без наследования/полиморфизма |
| Средства функционального программирования | Нет лямбд, `map/filter` и т.п. |

> **Критично для базы знаний:** при генерации кода **никогда** не использовать:
> - `new` / `delete` → использовать `malloc` / `free`
> - `cin` / `cout` → использовать `scanf` / `printf`
> - `class` → использовать `struct`
> - `&`-ссылки → использовать указатели `*`
> - `std::string` → использовать `char[]` / `char*`
> - `bool` без `<stdbool.h>` → в C99 подключить `<stdbool.h>` или использовать `int` (0/1)

## Ключевые выводы для шаблонов

1. **Всегда** подключать нужные заголовки: `<stdio.h>`, `<stdlib.h>`, `<string.h>`, `<math.h>` (по необходимости)

4. **Использовать `struct`** для пользовательских типов (с `typedef` или без — как в примерах преподавателя)
5. **Не использовать C++-конструкции** ни в каком виде
