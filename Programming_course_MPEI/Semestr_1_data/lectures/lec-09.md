# Лекция 9. Структурное программирование и подпрограммы (часть 2)

**Источник:** Лекция 8-9.pptx
**Диалект:** C (C99/C11) — теоретическая база

## 1. Передача параметров (слайд 16)

- По ссылке
- По указателю
- По значению

## 2. Типы параметров (слайд 17)

- Входные
- Выходные
- Промежуточные

## 3. Представление подпрограммы в методе (слайд 18)

Элементы:
- Входные параметры: X, nx
- Имя подпрограммы
- S = 0, k = 0
- Цикл i = 0..nx-1
  - Если X[i] < 0
    - Цикл j = 0..nx-1
    - S = S + X[i][j]
  - Иначе k = k + 1
- Если k == 0
  - S = "Нет таких строк"
- Выходные параметры: S

## 4. Правило для параметров (слайд 19)

- Неизменяемые переменные передаются только по значению
- Изменяемые переменные передаются только по ссылке\по указателю
- Параметры в C позиционные

## 5. Рекомендации (слайд 20)

- Подпрограмма взаимодействует с вызывающей программой с помощью параметров, а не за счет видимости глобальных
- Осуществляйте верное деление на подзадачи и все переменные, которые имеют отношение к алгоритму решения подзадачи делайте локальными и полностью подконтрольными ей.
