# База знаний: Программирование на C (Семестр 1)

Шаблоны кода и конспекты лекций для генерации решений в стиле преподавателя.

## Структура

- `/templates` — готовые шаблоны кода (C99)
- `/lectures` — конспекты по лекциям (lec-01.md ... lec-14.md)
- `rules.md` — правила для нейросети
- `style-guide.md` — особенности стиля преподавателя

## Использование

1. Нейросеть берет код только из `/templates`
2. Перед генерацией читает `rules.md`
3. Приоритет источников: docx-примеры > лекции > стандарт C
4. Оптимизация логики запрещена без согласования

## Для студентов

Клонируйте репозиторий и используйте шаблоны как основу для лабораторных. Не изменяйте структуру кода без необходимости.
